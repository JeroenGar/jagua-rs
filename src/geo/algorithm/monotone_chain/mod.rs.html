1//! Monotone Chains are a way of partitioning the segments of a linestring to allow for fast searching of intersections. They have the following properties:
2//!
3//! 1. the segments within a monotone chain never intersect each other
4//! 2. the envelope of any contiguous subset of the segments in a monotone chain is equal to the envelope of the endpoints of the subset.
5//!
6//! Property 1 means that there is no need to test pairs of segments from within the same monotone chain for intersection.  
7//! Property 2 allows an efficient binary search to be used to find the intersection points of two monotone chains. For many types of real-world data, these properties eliminate a large number of segment comparisons, producing substantial speed gains.  
8//!
9//! This module provides geometries backed by monotone chains.
10//!
