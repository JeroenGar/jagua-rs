Expand description

A point-like value that can be indexed in a BallTree.

Implemented for Point, Coord, and PointWithData. A collection of any BallTreePoint may be passed to BallTree::new or BallTreeBuilder::build. The associated Data type determines the payload returned from queries: it is () for bare points, and D for PointWithData<T, D>.
