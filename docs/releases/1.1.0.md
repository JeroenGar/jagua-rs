# jagua-rs 1.1.0

The collision engine is generic over its hazard entities, so it can be used with an
application's own item, container and layout types. Quality zones can serve as
collision targets for optimizers that quantify overlap. Polygon simplification no
longer enlarges an item's bounding box.

This release changes some public signatures. The JSON input format is unchanged.

## Highlights

- `CDEngine<E>` takes the hazard entity type, defaulting to `BasicHazardEntity`.
  Together with public snapshots, a layout outside this crate can register,
  deregister, save and restore hazards and run the same consistency checks.
- Quality zones have surrogates and can be narrowed cheaply with
  `InferiorQualityZone::filtered`.
- Simplified shapes stay within the original bounding box, so an item that fits its
  container keeps fitting after simplification.

## Changes

### Collision detection

- New trait `HazardEntity: Copy + Eq + Hash + Debug`, with `scope()` (interior or
  exterior) and `is_dynamic()` (whether the hazard can be registered and
  deregistered over time; only dynamic hazards are saved and restored). The
  previous enum is renamed `BasicHazardEntity` and implements it.
- `Hazard<E>`, `CDEngine<E>`, `CDESnapshot<E>` and `BasicHazardCollector<E>` take
  the entity type, defaulting to `BasicHazardEntity`. `HazardCollector` has an
  associated `Entity` type, and query callbacks receive `E`.
- `Hazard::new(entity, shape)` no longer takes a `dynamic` flag: the entity decides.
- `CDEngine::new` uses the single static hazard with exterior scope as the
  exterior, and panics if there are none or several.
- `CDEngine::haz_key(&entity)` replaces `haz_key_from_pi_key(pk)`.
- `HazardFilter<E>::is_irrelevant(key, entity)` receives the entity. A pair
  `(A, B)` of filters ignores what either ignores.
- `collect_poly_collisions(_until)` and `collect_surrogate_collisions(_until)` take
  a `filter`, like the `detect_*` queries. Collectors skip hazards they already
  hold, but are no longer filters themselves.
- `QualityZoneFilter { min_quality }` replaces
  `HazKeyFilter::from_irrelevant_qzones`.
- `CDEngine::save`, `CDEngine::restore` and `CDESnapshot` are public, with
  `CDESnapshot::dynamic_hazards` for read access.
- New `util::assertions::cde_matches_fresh(cde, base, dynamic_hazards)` checks that
  an engine matches a fresh copy of `base` with those hazards registered.
- `PItemKey` is defined in `collision_detection::hazards`. `entities` re-exports
  it, so `jagua_rs::entities::PItemKey` keeps working.

### Quality zones

- `InferiorQualityZone::new` takes an `SPSurrogateConfig` and generates a surrogate
  for every collision shape. `Importer::import_container` uses the importer's
  `item_surrogate_config`.
- `InferiorQualityZone::filtered` returns a zone with only the shapes whose
  collision contour satisfies a predicate. Kept shapes, including their surrogates,
  are shared rather than converted again. Hazard indices refer to the filtered
  zone's order.

### SVG export

- `s_layout_to_svg`, `layout_to_svg` and `layout_to_svg_group` take the layout's
  external `container_id`, as `export_layout_snapshot` does. The container group
  is named `container_{id}`, and item, surrogate and collision-shape definitions
  are named `item_{container_id}_{item_id}` and so on, so several layouts can share
  one document.

## Fixes

- Polygon simplification rejects candidates that would place a vertex outside the
  original bounding box. Before, merging two convex corners could make a shape
  taller or wider at a small area cost, so a fixed-orientation item that fit the
  strip could no longer be placed (JeroenGar/sparrow#176). The guarantee holds in
  the shape's own frame, so for rotations by multiples of 90°.
- Pier rays are generated relative to the shape's centroid. Shapes not centered on
  the origin could get rays with endpoints inside the shape. Imported items are
  centered, so their piers are unchanged.

## Migration

Code that used the `HazardEntity` enum uses `BasicHazardEntity`:

```rust
// 1.0.0
match entity {
    HazardEntity::PlacedItem { pk, .. } => {}
    HazardEntity::Exterior => {}
    _ => {}
}
// 1.1.0
match entity {
    BasicHazardEntity::PlacedItem { pk, .. } => {}
    BasicHazardEntity::Exterior => {}
    _ => {}
}
```

Collection queries take a filter. Pass `NoFilter` to keep the previous behavior:

```rust
// 1.0.0
cde.collect_poly_collisions(shape, &mut collector);
// 1.1.0
cde.collect_poly_collisions(shape, &NoFilter, &mut collector);
```

Hazard keys are looked up by entity:

```rust
// 1.0.0
let hkey = cde.haz_key_from_pi_key(pk);
// 1.1.0
let hkey = cde.haz_key(&BasicHazardEntity::from((pk, &layout.placed_items()[pk])));
```

Quality-zone filters no longer need the engine:

```rust
// 1.0.0
let filter = HazKeyFilter::from_irrelevant_qzones(min_quality, cde.hazards_map());
// 1.1.0
let filter = QualityZoneFilter { min_quality };
```

Code that constructs hazards drops the `dynamic` flag, and custom filters receive
the entity:

```rust
// 1.0.0
Hazard::new(entity, shape, dynamic);
fn is_irrelevant(&self, key: HazKey) -> bool;
// 1.1.0
Hazard::new(entity, shape);
fn is_irrelevant(&self, key: HazKey, entity: &E) -> bool;
```

`InferiorQualityZone::new` callers pass a surrogate configuration:

```rust
// 1.0.0
InferiorQualityZone::new(quality, shapes)?;
// 1.1.0
InferiorQualityZone::new(quality, shapes, cde_config.item_surrogate_config)?;
```

Use `SPSurrogateConfig::none()` for minimal surrogates.

SVG export callers pass the same ID they export: `0` for the SPP strip, the bin's
external ID for BPP.

```rust
// 1.0.0
s_layout_to_svg(snapshot, options, title);
// 1.1.0
s_layout_to_svg(snapshot, container_id, options, title);
```
