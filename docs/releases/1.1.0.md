# jagua-rs 1.1.0

Quality zones can now serve as collision targets for optimizers that quantify overlap,
and can be narrowed cheaply.

## Changes

- `InferiorQualityZone::new` takes an `SPSurrogateConfig` and generates a surrogate for
  every collision shape. `Importer::import_container` uses the importer's
  `item_surrogate_config`.
- `InferiorQualityZone::filtered` returns a zone with only the shapes whose collision
  contour satisfies a predicate. Kept shapes, including their surrogates, are shared
  rather than converted again. Hazard indices refer to the filtered zone's order.
- `s_layout_to_svg`, `layout_to_svg` and `layout_to_svg_group` take the layout's external
  `container_id`, as `export_layout_snapshot` does. The container group is named
  `container_{id}`, and item, surrogate and collision-shape definitions are named
  `item_{container_id}_{item_id}` and so on, so several layouts can share one document.
- `ShapeModifyConfig::offset` accepts a negative offset for `Deflate` shapes, such as container
  outlines: the outline grows, letting items come up to that much closer to its boundary, but no
  closer (within 1.1% of the offset). Inner corners of the grown outline are pulled back with a
  small V, so items keep a little more distance near them. Near narrow inlets, which growing
  would close, the original outline is kept. If the grown outline cannot be represented safely,
  the outline is kept as is, with a warning. A negative offset on an `Inflate` shape, such as a
  hole or quality zone, is an error: shrinking it could miss collisions at its corners and thin
  parts. This lets callers keep different distances from items and from the container boundary.

## Migration

`InferiorQualityZone::new` callers pass a surrogate configuration:

```rust
// 1.0.0
InferiorQualityZone::new(quality, shapes)?;
// 1.1.0
InferiorQualityZone::new(quality, shapes, cde_config.item_surrogate_config)?;
```

Use `SPSurrogateConfig::none()` for minimal surrogates.

SVG export callers pass the same ID they export: `0` for the SPP strip, the bin's
external ID for BPP.

```rust
// 1.0.0
s_layout_to_svg(snapshot, options, title);
// 1.1.0
s_layout_to_svg(snapshot, container_id, options, title);
```
